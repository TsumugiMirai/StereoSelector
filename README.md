# Stereo Selector

用于快速查看双目 RGB、深度图、伪彩图和 PLY 点云的数据工作台。它把常用的图片、深度、双目和点云检查集中在一个窗口中，专注于查看、测量和信息分析。界面参考 Codex 桌面版与 VS Code，面向熟悉数据处理的开发人员。

## 当前功能

- 单一查看工作流，不再提供模式切换或样本审核操作；工作区与单行播放器始终围绕数据查看设计。
- 左侧为默认折叠的 40 px 活动栏，按实际任务打开“数据、视图、显示调整、测量与选择、统计信息”；同一任务页根据数据源呈现图片或点云工具，不按参考应用划分入口。双目快捷操作集中在顶部检查栏，中央空间优先用于图片和点云。
- 顶部仅保留项目切换、打开项目、布局和设置；检查工具使用图标按钮和统一圆角悬停提示。
- `Tab` 隐藏或恢复全部界面工具，`F11` 全屏，`Ctrl+Shift+P` 打开可搜索的命令面板；双击视图标题可聚焦或退出聚焦。
- 选择文件夹后自动递归检查其中的视图目录，不要求使用固定的五个子文件夹名称；程序会结合文件夹/文件名、扩展名和图像位深推断数据类别。
- 当所选目录包含多个独立双目项目时，会自动识别为项目集合，并在顶部提供项目下拉切换；例如日期目录下的多个采集批次不会再合并为一个数据集。
- 项目不要求同时具备全部支持的数据类型；无法判断的目录仍可在视图映射中手动指定。
- 按相对路径和去除模态前后缀后的文件名匹配样本；支持场景子目录。
- 支持 `ColorLeft`、`ColorRight`、`DepthColor` 等驼峰式相机文件名。
- 文件名带采集序号但左右相机时间戳略有差异时，自动按采集序号配对，并保留场景目录防止跨场景混合。
- 左侧可勾选任意数量的模态并同步展示。
- 允许选择 0、1 或多种视图：未选择时显示空状态，单视图会占满工作区。
- 底部提供样本时间轴、上一帧/播放暂停/下一帧控制和 `0.5–10 fps` 速度选择；时间轴支持悬停帧号预览、单击精确跳转和拖动定位。
- 手动前后切帧会暂停播放；拖动时间轴暂时暂停，松开后按原状态继续，拖到末帧则停止。帧号和状态区保持固定宽度，长状态文字通过悬停查看。
- 支持将项目文件夹直接拖放到窗口打开。
- 启动时立即显示轻量启动页；进入主界面后保持空状态，不再自动弹出文件夹选择框。
- 支持常见 RGB、8/16 位灰度/深度图片；滚轮缩放、拖动平移、双击还原。
- 右侧检查器提供 RGB/灰度/深度直方图，以及最小值、最大值、均值、标准差、有效像素比例和文件信息。
- 文件信息保留原始尺寸，长路径中间省略，支持完整路径提示与一键复制。
- 支持亮度、对比度、Gamma、曝光、深度手动范围/自动百分位拉伸，以及灰度、Turbo、Viridis LUT。
- 可高亮深度 0、65535、非有限值和范围外像素；支持 1:1、适应窗口、适应宽度、矩形 ROI 统计、线段像素/标定长度测量和当前视图导出。
- 内嵌 PLY 点云预览，支持彩色/无色、ASCII/二进制 PLY；左键旋转、右键平移、滚轮缩放。
- 图片与点云在后台线程加载；切帧期间保留上一帧画布，新内容就绪后直接替换，不进行整幅淡入。首次慢加载才显示加载页，并缓存最近浏览内容。
- 显示调整和 ROI 统计在后台计算；快速拖动参数时合并等待中的预览请求，过期结果不会覆盖当前数据。
- 没有可用数据时禁用相应任务入口，加载期间禁用数据操作；ROI、线段、点选、点云框选和两点测距完成后返回平移/旋转模式，结果保留。重复点击工具或按 `Esc` 可取消。
- 当前帧显示后会低优先级预取后两帧和前一帧；缓存按估算内存限制淘汰，不再只按文件数量保留。
- 图片解码、图像/深度统计和点云处理使用独立后台任务；播放期间跳过完整统计，停止后再异步补齐。
- 可开启同步十字光标；在 RGB、伪彩图或深度图上检查时均可联动显示 RGB、匹配的原始深度值（附单位与米制换算），并在有标定时按深度图所在的校正坐标系计算相机坐标 XYZ（米）。
- 深度单位在“设置 → 标定”中显式选择：自动（整数深度按毫米、浮点按米）、毫米或米。光标 XYZ、线段长度和点云外参统一换算为米，不再按数值大小猜测。
- 线段测量对两端分别采样深度并显示端点深度；深度为 0、无效或 65535 饱和时明确提示，不给出错误长度。
- 可开启图片同步缩放和平移，也可查看左右图透明叠加和绝对差值；导入双目标定后可切换校正前/校正后图像，状态栏显示所用的校正方法（重映射表 / 校正参数 / 立体校正 / 仅去畸变），十字光标显示左右对应坐标与视差估计。
- 可将点云投影回左图；点击图片像素会在点云中高亮对应点，点选点云会在图片中显示对应位置。
- 深度质量面板独立加载当前匹配深度，显示有效范围、无效值、零值、空洞和包含 65535 饱和值的极大值比例。
- 支持导入 JSON、YAML 格式的左右目内参、畸变参数及双目外参；标定文件按项目记忆。
- 打开项目时自动发现随采集存放的标定（项目根目录或 `calib*` 子目录中的 JSON/YAML），列为“项目内”选项并在未选择标定时自动启用；这类选项只属于该项目，不会写入全局自定义列表。
- 内置 `libra2000`、`libra3000` 两套标定；主页面可快速切换，新增自定义标定统一在“设置 → 标定”中管理。标定分辨率与图像不一致时会提示一次。
- 厂商标定同时包含空气与水下（`uw`）两套校正参数时，检查栏出现“空气 / 水下”切换，默认空气，选择按项目记忆；水下项目应切到“水下”以获得正确的深度反投影和校正显示。
- 与标定 JSON 同目录的 `map_left_*.pfm` / `map_right_*.pfm` 重映射表会被读取并与 JSON 校验（自动识别上下翻转，判定所属模式）；校正显示在对应模式下直接使用设备自身的映射。
- 可显示左右目极线；标定文件含基础矩阵或完整双目标定时使用精确极线，否则按已校正图像显示水平参考线。
- 点云使用左相机坐标系正视：原点为左相机光心，X 向图像右侧、Y 向图像下方、Z 向相机正前方；有左目内参时按 `u=fx·X/(Z+cam_offset)+cx`、`v=fy·Y/(Z+cam_offset)+cy` 精确投影。
- 点云支持 RGB、X/Y/Z、相机深度和高度着色，坐标轴/网格/相机视锥，前后左右/俯视标准视角，深浅背景切换。
- 点云支持点选 XYZ/RGB/相机距离、两点距离测量、屏幕矩形框选、X/Y/Z 范围裁剪，以及实时点大小调整；当前视角可直接导出。
- 默认使用 `←` / `→` 切换样本、空格播放/暂停；设置页可自定义导航、播放与查看工具快捷键。
- `1`–`5` 切换对比视图，`F` 聚焦单视图，`Esc` 返回，`Ctrl+B` 隐藏/显示侧栏。
- 使用与工作区融合的深色标题栏，支持拖动、双击最大化以及最小化/最大化/还原/关闭。
- 提供统一的应用与任务栏图标，并使用 Windows 应用标识保持任务栏显示一致。
- 无边框窗口通过 Windows 原生命中测试支持四边、四角缩放与窗口吸附。
- 设置页支持黑色/白色主题、自定义快捷键，以及点云显示上限、虚拟相机后移、采样网格、点半径、最远距离、飞点过滤强度和近点遮挡。
- 左侧栏和顶部检查工具栏使用统一方向按钮收起与展开，一次提交布局变化，不连续缩放媒体画布；工作区采用克制的分隔线和统一圆角。
- 主页面、设置、映射与检查弹窗采用统一的圆角与状态层级；设置分页直接切换，保留开关等局部轻量反馈。
- 点云后端在启动页显示期间并行预热，点云视图持续复用，切换类别不会重建顶层窗口。
- 点云在后台完成坐标变换、默认 10 m 距离过滤、投影网格采样和飞点过滤；默认采样网格为 5 px、点半径为 1 px。开启遮挡时，同一网格保留最近点并按从远到近提交渲染。
- 打开、浏览和关闭项目均不自动复制样本，不创建 `_select` 目录或审核 JSON，也不读取、整理或删除已有审核输出。历史输出仍保留在磁盘上。
- 显示调整、ROI 和点云裁剪只影响当前视图，不修改源文件；需要保存画面时，可执行“导出当前视图”（屏幕截图）或“导出调整后图像”（按原始分辨率应用显示调整），并选择路径。
- 空状态页列出最近打开的项目，可一键重新打开。
- 应用日志写入用户数据目录（Windows 为 `%LOCALAPPDATA%\ToolBox\StereoSelector\logs\stereo_selector.log`），启动参数 `--verbose` 打开调试级别；打包版没有控制台时以此排查加载失败。
- 无法自动识别目录时，可手动指定所需视图文件夹；也可开启“按顺序强制匹配”，忽略文件名并按自然排序位置直接对应。
- 手动视图目录与强制匹配选项按项目分别保存，切换多个项目不会互相覆盖。

## 开发检查

```powershell
.\.venv\Scripts\python.exe -m ruff check src scripts tests
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m pytest -q
```

依赖只在 `pyproject.toml` 声明；版本号也只在那里维护，`stereo_selector.__version__`、打包文件名和 Windows 版本资源都由它派生。可选安装 `pre-commit` 后执行 `pre-commit install`，提交前自动运行 ruff。

## 安装与运行（Windows）

需要 Python 3.10–3.13，推荐 Python 3.12。首次运行：

```powershell
.\setup.ps1
.\run.ps1
```

也可从命令行直接打开项目：

```powershell
.\run.ps1 D:\data\capture_project
```

## 可选：打包 EXE

```powershell
.\build_exe.ps1
```

日常源码更改无需执行打包。仅在需要发布版本时手动运行以上命令，v1.1 输出为 `dist\StereoSelector-v1.1.exe`。

发布构建可使用内置冒烟测试验证全部图片和点云渲染器：

```powershell
.\dist\StereoSelector-v1.1.exe --smoke-test D:\data\capture_project
```

退出码 `0` 表示全部可用，`2` 表示至少一种渲染器失败，`3` 表示加载超时。

## 匹配约定

最稳妥的命名是各目录使用相同文件名，例如 `000001.png` / `000001.ply`。程序也会匹配如下名称：

```text
left/left_rgb_000001.png
right/right_rgb_000001.png
depth_fsd/depth_000001.tiff
depth_color/depth_color_000001.png
ply/000001.ply
```

如有多个场景，可以保持镜像结构：

```text
project/
  scene_01/left/...
  scene_01/right/...
  scene_02/left/...
  scene_02/right/...
```

如果各视图的文件名完全不同，点击侧栏中的“配置视图与匹配”，选择对应文件夹并开启“按顺序强制匹配”。程序会将各目录自然排序后的第 1、2、3…个文件直接组成同一组；文件数量不同时，超出部分会作为缺少部分视图的样本保留。

## 标定文件

支持 JSON、YAML 和 OpenCV YAML。常用 JSON 结构如下：

```json
{
  "left": {
    "width": 1280,
    "height": 720,
    "camera_matrix": [[800, 0, 640], [0, 800, 360], [0, 0, 1]],
    "distortion": [-0.1, 0.01, 0, 0, 0]
  },
  "right": {
    "camera_matrix": [[800, 0, 640], [0, 800, 360], [0, 0, 1]],
    "distortion": [0, 0, 0, 0, 0]
  },
  "left_to_right": {
    "rotation": [[1, 0, 0], [0, 1, 0], [0, 0, 1]],
    "translation": [-0.12, 0, 0]
  },
  "cloud_to_left": {
    "rotation": [[1, 0, 0], [0, 1, 0], [0, 0, 1]],
    "translation": [0, 0, 0]
  }
}
```

也识别 OpenCV 常见的 `M1`、`D1`、`M2`、`D2`、`R`、`T`、`F` 字段，以及厂商格式的 `camera_left` / `camera_right` / `extrinsic_l_r` / `camera_rectify` / `camera_rectify_air`。

坐标系与单位约定：

- 平移向量模长大于 1.5 时视为毫米，否则视为米；也可在文件中用 `unit: "mm"` 显式声明。基线与 `cloud_to_left` 平移都会按此换算为米。
- 深度图和设备点云位于校正后的左目坐标系。存在 `camera_rectify`（或 `camera_rectify_air`）时，光标 XYZ、线段长度和点云投影使用其中的校正焦距与主点；否则回退到原始左目内参并迭代去畸变。
- `camera_rectify_air` 存在或文件含 `uw_*` 字段时，`camera_rectify` 被视为水下参数，界面提供空气/水下切换。
- `cloud_to_left` 会在显示前把 PLY 从其原坐标系变换到左目相机坐标系。

## GitHub Actions 跨平台构建

`.github/workflows/build-desktop.yml` 会在主分支更新、面向主分支的 PR、版本标签以及手动运行时执行测试并构建桌面包。v1.1 生成以下文件：

| 平台 | 输出 |
| --- | --- |
| Windows x64 | `StereoSelector-v1.1.exe` |
| macOS Intel | `StereoSelector-v1.1-macOS-x64.dmg` |
| macOS Apple Silicon | `StereoSelector-v1.1-macOS-arm64.dmg` |
| Linux x64（Ubuntu 20.04 / glibc 2.31 及以上） | `StereoSelector-v1.1-linux-x86_64.AppImage` |

每次构建的文件会作为 Actions artifact 保留 30 天。推送与项目版本一致的 `v*` 标签时，工作流也会把四个平台包上传到已有 GitHub Release。若标签已经存在，可从 Actions 手动运行工作流并在 `release_tag` 中填写 `v1.1`。

macOS 包目前使用临时签名，没有 Apple Developer ID 公证；首次打开时可能需要在系统“隐私与安全性”中确认。Linux AppImage 仍依赖目标机器提供可用的图形桌面、OpenGL 驱动和基础系统图形库。

Linux 包在官方 `ubuntu:20.04` 容器中使用 Python 3.11 和受约束的 PySide6 6.7.3 构建，并在 glibc 2.31 环境中完成单元测试和最终 AppImage 冒烟测试。它适用于 x86_64 架构的 Ubuntu 20.04 及更新版本；不支持 ARM64 或基于 musl libc 的发行版。

## UI 开发约定

后续主界面、设置页、对话框和新控件均遵循 [UI 前端规范](docs/UI_FRONTEND_SPEC.md)。规范定义了深浅主题令牌、字体、间距、圆角、组件尺寸、交互状态、动画和变更验收清单；新增 UI 不应再创建独立的一套样式。

ImageJ、CloudCompare 与双目专用能力的完成度统一记录在 [功能矩阵](docs/IMAGEJ_CLOUDCOMPARE_FEATURE_MATRIX.md)，新增或删除检查功能时应同步更新统计。

可对真实项目执行只读界面验证：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe scripts/check_ui_workflows.py D:\data\capture_project
```

脚本检查任务页切换、深浅主题和窗口尺寸，将截图与临时设置保存在临时目录，并比较运行前后的源目录及同级 `<项目名>_select` 目录清单、文件大小和修改时间；已有审核 JSON 还会进行小文件内容摘要校验。此检查不向源项目写入文件，界面切换耗时也不等同于实际点云帧率。
