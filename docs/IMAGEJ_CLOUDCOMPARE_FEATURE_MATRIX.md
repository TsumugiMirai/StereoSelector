# ImageJ / CloudCompare 功能矩阵

更新时间：2026-09-04

Stereo Selector 的目标是快速查看和检查双目数据，不是完整复制 ImageJ 或 CloudCompare。下表用于明确已经可用、部分可用和后续仍缺少的高频能力。应用只保留查看工作流；ROI、框选和裁剪均为查看分析工具，不代表样本审核或文件筛选。

## 统计摘要

| 功能域 | 已完成 | 部分完成 | 未完成 |
| --- | ---: | ---: | ---: |
| ImageJ 高频图像能力 | 12 | 2 | 8 |
| CloudCompare 高频点云能力 | 13 | 3 | 9 |
| 双目专用能力 | 9 | 0 | 4 |

## ImageJ 高频图像能力

### 已完成（12）

| 类别 | 当前能力 |
| --- | --- |
| 像素检查 | 显示坐标、RGB、原始深度和有标定时的 XYZ |
| 直方图 | RGB、灰度和深度直方图 |
| 基础统计 | 最小值、最大值、均值、标准差、有效像素比例和像素数 |
| 显示调整 | 亮度、对比度、Gamma、曝光 |
| 深度显示 | 手动范围、自动百分位拉伸、Gray/Turbo/Viridis LUT |
| 无效值检查 | 高亮 0、65535、非有限值和越界值 |
| 导航 | 1:1、适应窗口、适应宽度、平移和滚轮缩放 |
| ROI | 矩形 ROI 及区域统计 |
| 测量 | 线段像素长度；有标定时显示物理长度 |
| 导出 | 当前图片或点云视图截图 |
| 序列查看 | 时间轴、逐帧切换和连续播放 |
| 深度质量 | 有效范围、零值、空洞、无效值和极大值比例 |

### 部分完成（2）

| 功能 | 当前限制 |
| --- | --- |
| ROI 工具 | 只有矩形 ROI 和线段；没有椭圆、多边形、自由手绘和 ROI 管理器 |
| 空间标尺 | 可计算标定后的线段长度；没有独立比例尺、单位管理和比例尺叠加层 |

### 未完成（8）

1. 线剖面和灰度/深度 Profile 曲线。
2. 阈值、分割、二值掩膜及区域连通分析。
3. 模糊、锐化、边缘检测、形态学等图像滤波。
4. 通道拆分/合并、位深转换和颜色空间转换。
5. 文字、箭头、标尺等持久化叠加标注及 Overlay 管理。
6. 宏、插件和批处理流水线。
7. 图像算术、FFT、频域检查等分析能力。
8. Montage、Reslice、正交切面和体数据三维查看。

## CloudCompare 高频点云能力

### 已完成（13）

| 类别 | 当前能力 |
| --- | --- |
| PLY 读取 | ASCII/二进制、带 RGB 或无颜色 PLY |
| 相机坐标 | X 向右、Y 向下、Z 向前，并支持外参变换到左相机 |
| 着色 | RGB、X、Y、Z、相机深度和高度 |
| 辅助对象 | 坐标轴、网格、相机光心和视锥 |
| 标准视角 | 前、后、左、右和俯视 |
| 点选 | XYZ、颜色和相机距离 |
| 测距 | 两点三维距离 |
| 选择 | 屏幕矩形框选 |
| 裁剪 | X/Y/Z 数值范围裁剪 |
| 过滤 | 最远距离、网格采样、飞点过滤和近点遮挡 |
| 显示 | 点大小、采样密度和深浅背景 |
| 统计 | 点数、原始点数、包围范围 |
| 导出 | 当前点云视角截图 |

### 部分完成（3）

| 功能 | 当前限制 |
| --- | --- |
| 文件格式 | 目前只正式支持 PLY；没有 LAS/LAZ、PCD、E57、OBJ 等格式 |
| 局部选择 | 可框选和恢复全部点，但不能把选区另存为新点云 |
| 距离过滤 | 可在设置中控制最远距离；尚无直接位于点云视图上的交互式距离滑块 |

### 未完成（9）

1. 多点云同时加载、实体树和显示/隐藏管理。
2. 点云配准、手动对齐和 ICP。
3. 点云到点云、点云到网格的距离计算。
4. 法向量估计、显示和方向统一。
5. 标量场运算、颜色标尺和标量场筛选。
6. 平面拟合、截面提取和交互式分割。
7. SOR、半径离群点等统计去噪。
8. 三角网格生成、网格查看和网格测量。
9. 将裁剪、筛选或变换后的点云导出为新文件。

## 双目专用能力

### 已完成（9）

1. 左右图同步缩放和平移。
2. 左右图透明叠加。
3. 左右图绝对差值。
4. 极线与像素联动。
5. 校正前/校正后切换。
6. 左右对应坐标和局部视差估计。
7. RGB、伪彩图与原始深度的同步像素检查。
8. 点云重新投影到左图。
9. 图片像素与点云三维点的双向联动。

### 未完成（4）

1. 标定重投影误差的自动统计和合格判定。
2. 多种稠密视差/深度结果的误差对比。
3. 双目错配、校正偏差和深度异常的批量自动检测。
4. 多套标定参数的同屏 A/B 对比。

## 界面分区

界面入口按工作流拆分为：

- 数据：项目、目录识别和视图映射。
- 视图：当前需要显示的数据类型和深度质量。
- 显示调整：亮度、对比度、Gamma、曝光、深度范围/LUT；点云着色、点大小、标准视角、背景与辅助线；当前视图导出。
- 测量与选择：图片 ROI、线段测量与适应视图；点云点选、两点测距、框选和坐标范围裁剪；共享结果区。
- 统计信息：图片直方图、有效像素与统计；点云点数与坐标范围；文件信息。

双目同步、极线、校正和透明叠加集中在顶部检查栏；绝对差值与点云投影也可从命令面板调用，不再在左侧设置重复工作栏。

ImageJ / CloudCompare 仅作为本文的能力对照来源，不作为应用内的功能分类。任务页按当前数据源显示适用内容；无项目、无可见数据时不能打开无内容的任务页。

## 数据安全边界

浏览和分析不修改源数据，不自动创建 `_select` 目录或审核 JSON，不读取或整理历史审核记录。旧版本创建的输出保持原样，不因升级自动删除。当前视图截图仍可由用户主动导出；将处理后的图片或点云另存为新数据不在现有导出能力内。
