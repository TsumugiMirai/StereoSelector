# Stereo Selector UI 前端规范

规范修订：2026-09-04（应用版本独立维护）
适用范围：Stereo Selector 的所有 PySide6 主窗口、工具栏、侧栏、检查器、设置页、对话框与浮层。

## 1. 设计目标

Stereo Selector 是面向熟练开发人员的双目数据快速查看器。界面必须优先保证数据可视面积、信息密度和操作速度，所有入口围绕查看、测量和信息分析组织。

产品只保留查看工作流：不提供模式切换、样本接受/拒绝、标签备注或输出目录管理。不得在打开、切换、关闭项目时创建 `_select` 目录或审核 JSON；不得修改或删除历史审核输出。导出当前视图仍是明确触发、用户选择目标路径的独立操作。

设计取向来自 Codex Desktop 与 VS Code 的共同规律：

- 固定区域扁平化，以背景层级和 1 px 分隔线建立结构。
- 阴影仅用于对话框、菜单、命令面板等浮动表面。
- 工具默认使用图标，名称和快捷键放在提示中。
- 选中、悬停、按下和键盘焦点必须可区分，但不使用大面积高饱和色。
- 主界面保持紧凑；设置页可以适度留白，但组件规则必须一致。
- 深色和浅色主题使用同一布局、尺寸和交互，只替换颜色令牌。

参考基线：

- Codex Desktop 26.721：12/14 px 正文字号、4 px 间距基线、36/40/46 px 工具栏、4–12 px 分级圆角、150 ms 基础过渡。
- VS Code 2026 Dark / Light：编辑区与侧栏分层、1 px hairline、清晰的焦点色、扁平活动栏和检查器。

不得逐页临时决定颜色和尺寸。新增 UI 必须先使用本文件已有令牌；确实缺少时，先扩展规范再写代码。

## 2. 信息架构

主窗口从外到内为：

1. 标题栏：品牌、当前项目、打开项目、布局、设置、窗口控制。
2. 主体：
   - 左侧 40 px 活动栏。
   - 按需展开的 220–360 px 导航侧栏。
   - 中央媒体工作区。
   - 按需展开的 268–380 px 检查器。
3. 底部单行播放器，显示播放控制与当前数据状态。

规则：

- 不再在标题栏下重复放置“打开 / 布局 / 设置”工具栏。
- 图片和点云区域必须是窗口扩展时的第一伸缩目标。
- 不保留隐藏的审核面板、快捷键或命令入口；旧的模式设置不得影响新界面。
- `Tab` 隐藏全部界面 chrome，媒体网格间距降至 1 px。
- 双击媒体标题聚焦；焦点模式只保留一个媒体视图。
- 活动栏按实际任务划分为“数据、视图、显示调整、测量与选择、统计信息”，不按 ImageJ / CloudCompare 等参考应用划分。
- 显示、测量、统计页共享数据源选择；同一任务根据图片/点云呈现适用控件，不显示无效的另一套工具。
- 无项目时仅允许打开数据入口；无可见数据时关闭并禁用分析任务入口。命令面板和快捷键使用相同前置检查。
- 左侧导航内容与右侧任务检查器互斥展开，避免压缩工作区；活动栏始终保持固定宽度。

## 3. 设计令牌

### 3.1 颜色

颜色在 `src/stereo_selector/theme.py` 的 `PALETTES` 中维护。控件 QSS 不得直接新增与语义重复的十六进制颜色。

| 语义 | 深色 | 浅色 | 用途 |
|---|---:|---:|---|
| `window` | `#191A1B` | `#FAFAFD` | 标题栏、活动栏、状态区域 |
| `sidebar` | `#191A1B` | `#FAFAFD` | 导航侧栏、检查器底色 |
| `surface` | `#121314` | `#FFFFFF` | 主工作区与页面 |
| `panel` | `#202122` | `#FAFAFD` | 控件、浮层、次级表面 |
| `elevated` | `#242526` | `#F0F0F3` | 选中项、输入辅助底色 |
| `input` | `#191A1B` | `#FFFFFF` | 输入框、选择框 |
| `border` | `#2A2B2C` | `#F0F1F2` | 固定面板 hairline |
| `border_strong` | `#333536` | `#D8D8D8` | 输入框、浮层边框 |
| `text` | `#EDEDED` | `#202020` | 标题与主要信息 |
| `text_secondary` | `#BFBFBF` | `#606060` | 正文与次要信息 |
| `muted` | `#8C8C8C` | `#606060` | 元数据、提示 |
| `faint` | `#626262` | `#999999` | 禁用前的弱信息 |
| `hover` | `#28292A` | `#EEEEF1` | 悬停 |

### 3.2 字体

字体回退顺序：

```text
"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif
```

等宽信息：

```text
"Cascadia Mono", "SFMono-Regular", "Consolas", "Microsoft YaHei UI"
```

字号与字重：

| 层级 | 大小 | 字重 | 用途 |
|---|---:|---:|---|
| Caption | 11 px | 400/500 | 元数据、状态、快捷键 |
| Body | 12 px | 400 | 控件、正文 |
| Body strong | 12 px | 600 | 面板标题、媒体标题 |
| Heading S | 14 px | 600 | 设置分组、小页面标题 |
| Heading M | 18 px | 600 | 设置页标题 |
| Empty title | 20 px | 600 | 空状态 |

禁止用全角空格或重复空格制造布局。英文大写眉题仅在极少数导航分组使用。

### 3.3 间距

以 4 px 为基线：`2, 4, 6, 8, 12, 16, 20, 24, 32`。

- 图标内部：2–4 px。
- 同组控件：4–6 px。
- 工具栏水平间距：4 px。
- 固定面板内边距：8–12 px。
- 设置页内容边距：24 px。
- 媒体网格：8 px；纯查看模式：1 px。
- 禁止出现没有语义的 10、14、18 px 混用；旧代码可以逐步收敛。

### 3.4 尺寸

| 组件 | 高度/宽度 |
|---|---:|
| 标题栏 | 40 px |
| 次级工具栏 | 38 px |
| 活动栏 | 40 px |
| 活动按钮 | 36 × 36 px |
| 标准按钮/选择框 | 28 px |
| 紧凑图标按钮 | 28 × 28 px |
| 窗口控制按钮 | 42 × 32 px |
| 检查器标题栏 | 38 px |
| 底部播放器 | 40 px |
| 设置导航 | 176 px |

可点击目标不小于 28 × 28 px。边框调整大小的系统命中区不属于可见尺寸，应保持至少 7 px。

### 3.5 圆角

| 令牌 | 数值 | 用途 |
|---|---:|---|
| `radius_xs` | 4 px | 复选框、进度条 |
| `radius_sm` | 6 px | 图标按钮、列表项 |
| `radius_md` | 8 px | 输入框、媒体视图 |
| `radius_lg` | 10 px | 菜单、命令面板 |
| `radius_xl` | 12 px | 模态对话框 |
| `radius_full` | 999 px | 状态胶囊、开关 |

固定侧栏、工具栏、检查器、状态栏不使用外轮廓圆角。禁止在一个 8 px 圆角卡片内继续嵌套 10 px 圆角卡片。

### 3.6 阴影与层级

Qt 固定面板不模拟阴影，使用分隔线。阴影仅用于：

- 菜单、选择器弹层：`0 4 8 -2 rgba(0,0,0,.10)` 的视觉等级。
- 命令面板：`0 8 16 -4 rgba(0,0,0,.18)`。
- 模态对话框：`0 16 32 -8 rgba(0,0,0,.28)`。

PySide 中通过 `QGraphicsDropShadowEffect` 或现有 `ShadowDialog` 实现。不要给每个媒体视图和检查器分组加阴影。

## 4. 组件规范

### 4.1 标题栏

- 左侧：23 px 应用标记与产品名。
- 中部：当前项目名，单行省略。
- 右侧：打开项目、布局、设置，随后是系统窗口控制。
- 主要操作只允许一个实心按钮；其他操作使用幽灵或边框按钮。
- 窗口控制图标必须绘制或使用统一 SVG，不使用字符 `— □ ×`。
- 标题栏空白区域支持拖动，双击切换最大化。

### 4.2 活动栏和侧栏

- 活动栏固定 40 px，图标 16–18 px。
- 选中态使用弱背景和 2 px 左侧焦点线。
- 侧栏内容按当前活动页切换，不同时堆叠所有功能。
- 双目同步、极线、校正和叠加属于顶部高频检查工具，不在活动栏重复设置分类。
- 标定选择器右侧的“空气 / 水下”校正模式选择器只在当前标定同时包含两套校正参数时出现；默认空气，选择按项目记忆，并与标定选择器使用同一 `ChoiceButton` 样式。
- 侧栏分组默认扁平；仅需要独立边界的摘要可使用低对比面板。
- 展开/折叠一次提交最终布局，内容显隐、宽度限制、选中图标必须同步。禁止动画连续修改媒体工作区尺寸。

### 4.3 媒体视图

- 外圆角 8 px，1 px 边框。
- 标题栏高度约 32 px，内边距 `8 × 6 px`。
- 标题、文件名、聚焦按钮保持单行，文件名中间省略。
- 加载延迟出现，已显示内容不应被瞬间替换为加载页。
- 聚焦态只改变边框/焦点线，不改变整体尺寸，避免布局抖动。
- 缺失、错误、加载中分别使用 warning、danger、muted 语义。

### 4.4 检查器

- 固定右侧，无外圆角、无阴影。
- 分组使用标题、8 px 内容间距和底部分隔线；避免“卡片套卡片”。
- 高频控制在上，统计和文件信息在下。
- 滑块标签左对齐，数值使用等宽字体并右对齐。
- 多个互斥工具使用分段控件或可选按钮，不混用多种选中样式。
- 切换数据源时恢复该数据源的参数，不能把上一个数据源的滑块值应用到新数据源；加载期间禁用操作。
- RGB 图片隐藏深度专用范围/LUT 控件。点云统计只在数据变化后重新计算包围范围。
- ROI、线段、点选、框选、两点测距为一次性工具，完成后返回平移/旋转并保留结果；切帧清理过期测量。
- 重复点击当前工具或按 `Esc` 取消；切换任务页、数据源或进入设置也取消未完成工具。

### 4.4.1 十字标线读数

- 十字标线开启后，顶部检查栏增加一行右对齐读数区；关闭后恢复单行高度。
- 读数固定分为位置、左右匹配、RGB、深度和 XYZ 五个语义列，禁止使用整段右对齐字符串。
- 字段数值变化不能改变相邻字段的起点；完整内容同时写入悬停提示。
- 在 1050 px 最小窗口宽度下，读数区右边界不得超出工作区。

### 4.5 播放器

- 始终使用单行 40 px 播放器，控件名统一为 `player_bar`，不得沿用审核栏语义。
- 顺序：上一帧、播放、下一帧、当前帧、时间轴、总帧数、速度、状态。
- 播放按钮的播放/暂停图标在原位置切换，不改变按钮宽度。
- 手动前后切帧暂停播放；拖动时间轴临时暂停，释放后按原状态恢复，到达末帧停止。单帧项目不启用播放。
- 帧号宽度按总帧数字数一次确定，状态文本固定宽度并省略；悬停不能改变滑块手柄尺寸。
- 帧号、时间轴和播放状态不依赖已检查、接受或拒绝等样本标签。
- 没有数据时禁用播放和跳转；加载、播放、就绪等状态使用固定占位，避免文本变化挤压时间轴。

### 4.6 表单

- 输入、选择和按钮默认高 28 px、圆角 6–8 px。
- 同一页面的下拉选择必须全部使用 `ChoiceButton`，不混入原生 `QComboBox`。
- `ChoiceButton` 的列表必须使用主窗口内部的 `ChoicePopup`；禁止退回原生 `QMenu` 或系统组合框弹窗。
- 下拉浮层由透明阴影层和单一圆角表面构成，不能同时叠加原生方形窗口背景。
- 相同选项复用现有列表控件，不在每次展开/选择时销毁重建。浮层独占方向键、回车和 Escape，不能触发底层切帧或查看工具快捷键。
- 焦点使用 `focus` 色 1 px 边框；悬停不能覆盖焦点状态。
- 禁用态保持可读，禁止仅用透明度低于 40% 表示。
- 标签位于左侧时保持固定语义列；复杂说明放在标题下方，不塞进按钮文字。

### 4.7 设置页

- 嵌入主窗口时不显示第二个外框或第二套窗口标题栏。
- 导航宽 176 px，列表项高约 34 px。
- 页面边距 24 px，标题 18 px。
- 设置行采用扁平分隔列表；仅在需要强调为独立模块时使用卡片。
- 底部操作栏固定，右侧“取消 / 保存”，左侧“恢复默认”。

### 4.8 菜单、提示和命令面板

- 菜单圆角 8–10 px、5 px 内边距、1 px 强边框。
- Tooltip 内容格式：`功能名称 (快捷键)`；不要写说明段落。
- Tooltip 不使用危险红色，关闭按钮也遵循同一提示样式。
- Tooltip 管理器必须在父窗口/浮层销毁和应用退出前解除全局事件监听，清理应支持重复调用。
- 文件路径在窄检查器中采用中间省略，完整信息放入悬停提示，并提供复制路径按钮；不得因预览降采样改变原始尺寸显示。
- 命令面板宽约 620 px，搜索框与结果无重复外框，当前项使用明确选中背景。

## 5. 状态矩阵

每个交互控件至少实现：

| 状态 | 表现 |
|---|---|
| Default | 透明或 panel 背景，正常文字 |
| Hover | `hover` 背景，边框最多增强一级 |
| Pressed | `pressed` 背景 |
| Checked/Selected | `selection` 背景，可附 2 px focus 线 |
| Keyboard focus | `focus` 边框，不能仅靠背景 |
| Disabled | disabled 文本和低对比边框，不响应 hover |
| Loading | 保留布局，延迟显示 spinner |
| Error | danger 文本/边框，提供可恢复操作 |
| Success | success 状态线/文本，不大面积使用纯绿色 |

按钮 hover 不应把浅色主题文字变成与背景相同的颜色。

## 6. 动效与响应

- 局部按钮/开关可使用 100–150 ms 反馈；媒体流畅性优先于装饰动画。
- 侧栏、检查栏和设置分页直接切换；一次完成布局提交，不叠加互相抢占的动画回调。
- 图片、点云及包含它们的容器不使用 `QGraphicsOpacityEffect`；不得逐帧淡入，不得隐藏再显示仍在使用的画布。
- 新内容未就绪时保留上一帧，并以标题加载状态说明；首次打开没有旧内容时才使用完整加载页。
- 加载不足 180–220 ms 时不显示 spinner。
- 解码、统计、点云处理、显示预览使用独立队列；后台只处理数组和 QImage，QPixmap/控件更新在主线程完成。
- 连续调整显示参数时，每个视图最多一个预览运行、一个最新请求待处理；旧任务完成不得覆盖新帧。ROI 结果也必须校验请求序号。

## 7. 图标

- 图标使用代码绘制或统一的单色 SVG，线宽约 1.25–1.5 px。
- 默认 16–18 px，位于 28–36 px 点击区域内。
- 同一工具栏不混合字符图标、平台图标和粗细不同的 SVG。
- 图标颜色来自 `text_secondary / muted / disabled / focus`。
- 纯图标按钮必须有 Tooltip 和无障碍名称。

## 8. 文案

- 按钮使用动词或对象：`打开项目`、`适应窗口`、`导出视图`。
- 无需解释显而易见的结果，不在主界面重复操作说明。
- 省略号 `…` 表示点击后仍需用户输入。
- 状态尽量短：`加载中`、`播放中`、`无标定`。
- 技术参数可保留英文缩写，如 `ROI`、`Gamma`、`XYZ`，说明放在 Tooltip 或设置页。

## 9. 可访问性与输入

- 正文对比度目标不低于 4.5:1，弱元数据不低于 3:1。
- 键盘焦点必须可见。
- 所有鼠标操作应有快捷键或能从命令面板访问。
- 不仅依靠红/绿区分状态，同时使用文字和边线。
- 图片检查十字光标不能被手形鼠标遮挡。
- 高 DPI 下绘制线条使用 cosmetic pen，避免缩放后粗细不一致。

## 10. PySide6 实现约束

- 主题颜色只来自 `PALETTES`，由 `style_for()` 生成。
- 组件语义由稳定的 `objectName` 或动态 property 表达。
- 动态 property 改变后必须执行 `unpolish / polish`。
- 控件尺寸在 Python 中设置，颜色和状态在 QSS 中设置。
- 禁止为单个控件调用大段 `setStyleSheet()`；媒体类型强调色等真正动态颜色除外。
- 浮层统一使用 `ShadowDialog`、`ChoiceButton` / `ChoicePopup` 和 `DialogCloseButton`。
- 图标绘制逻辑集中在 `widgets.py`，不要在业务页面重复画同一图标。
- 新界面需要同时在 dark/light 下检查，且最小窗口尺寸不得重叠。

## 11. UI 变更验收清单

提交任何 UI 修改前逐项检查：
